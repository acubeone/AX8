## NOT - Logical NOT

### Summary

Performs logical operation `NOT` at destination and store result in destination
location.

### Operation

```
[dst] <- ~[dst]
```

### Syntax

```asm
NOT <dreg>
```

### Condition Codes

|  N  |  V  |  C  |  Z  |
| :-: | :-: | :-: | :-: |
| `*` | `0` | `0` | `*` |
