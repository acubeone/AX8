## NOP - No Operation

### Summary

This operation does nothing and performs no computation. Execution continues
normally after this instructions, the processor state is not modified. This
instruction effectivelly just consume cycles.

### Operation

```
None
```

### Syntax

```asm
NOP
```

### Condition Codes

|  N  |  V  |  C  |  Z  |
| :-: | :-: | :-: | :-: |
| `.` | `.` | `.` | `.` |
